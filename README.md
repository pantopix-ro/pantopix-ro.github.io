# pantopix.ro

The website of PANTOPIX RO SRL. Next.js, exported as static HTML and hosted on GitHub Pages. Content lives in `content/` as Markdown and JSON, editable by hand, by Claude Code or in TinaCMS.

## Run it

```sh
npm install
npm run dev        # http://localhost:3000
npm run cms        # same, plus the TinaCMS editor at /admin/index.html
npm test           # canvas animation tests
npm run build      # static site in out/
```

## Where things are

| Path | What |
|---|---|
| `content/pages/home.json` | Homepage text |
| `content/pages/audit.json` | Free audit page |
| `content/pages/privacy.md` | Privacy policy |
| `content/services/*.md` | One file per service. `group` is Build, Run or Join |
| `content/insights/*.md` | Articles. `draft: true` lists the card as "coming soon" without a page |
| `content/team/team.json` | Team members and photos (`public/team/`) |
| `content/site/site.json` | Navigation, contact details, legal data |
| `src/anim-src/` | Hand-written canvas animations and their tests |
| `public/anim/` | Generated by `npm run anim` (and before every build). Don't edit |
| `tina/config.ts` | TinaCMS schema |

## Animations

Plain ES5 canvas code, no libraries.

- `stream.js` is the hero's live event stream. On touch screens its labels step through the diagram as the page scrolls. A tap or a mouse move hands control back to the visitor.
- `metro.js` draws the metro map on /process/. `journeys.js` holds its data: one line per starting point, from Strategy/What We Offer.md in the vault. `iso.js` draws the station scenes.

After editing anything in `src/anim-src`, run `npm test` and `npm run anim`.

## Deploy

Every push to `main` runs `.github/workflows/deploy.yml`, which tests, builds and publishes `out/` to GitHub Pages.

One-time setup:
1. In the repository, go to Settings → Pages → Source and choose "GitHub Actions".
2. For the pantopix.ro domain, enter it under Settings → Pages → Custom domain, and point DNS at GitHub Pages. That means A records for `pantopix.ro` to 185.199.108.153, 185.199.109.153, 185.199.110.153 and 185.199.111.153, plus a CNAME for `www` to `pantopix-ro.github.io`. Then add `public/CNAME` containing `pantopix.ro`.

## Editing with TinaCMS

Locally, `npm run cms` saves edits straight to the files in `content/`, and you commit them as usual. For editing on the live site, create a Tina Cloud project linked to this repository. Then set `NEXT_PUBLIC_TINA_CLIENT_ID` and `TINA_TOKEN` as repository secrets and change the build step to `npm run build:cms`.

## Forms

GitHub Pages has no server. The audit form opens the visitor's mail program, addressed to salut@pantopix.com, with the request filled in. To receive submissions directly, point `src/components/AuditForm.tsx` at a form service, then update the privacy policy.
